# [Вопросно-ответная система для консультации иностранных студентов]

> Вопросно-ответная система, которая помогает иностранным студентам находить ответы на вопросы по регламентам СПбПУ, извлекая цитаты из официальных документов со ссылкой на источник.

**Команда:** Мария Юртаева и Вероника Ильина  
**Трек B:** Семантический поиск по коллекции  
**Дисциплины:** Автоматическая обработка естественного языка · Основы Web программирования

## Задача

**Вход:** `{query}`  
**Выход:** `{answer, sources: [{document, section, text}], confidence}`

**Пример входа:**
```

"Где находится отдел, куда нужно отнести паспорт для продления визы?"

```

**Пример выхода:**
```json
{
  "answer": "в Паспортно-визовый отдел СПбПУ (Гражданский пр., д. 28, 112 кабинет)",
  "sources": [
    {
      "document": "Инструкция по продлению учебной визы для иностранных граждан",
      "section": "Шаг 2. Подача документов",
      "text": "Для продления срока действия учебной визы иностранный обучающийся обязан не позднее чем за 45 дней до истечения срока действия текущей визы предоставить пакет документов в Паспортно-визовый отдел СПбПУ (Гражданский пр., д. 28, 112 кабинет)."
    }
  ],
  "confidence": 0.89
}
```

## Запуск

**Модель:**
```bash
python src/predict.py --text "текст для проверки"
```

**Сервис:**
```bash
uvicorn web.main:app --reload
```

Документация API: http://127.0.0.1:8000/docs
